# PE Static Sentinel - 项目总览

## 项目愿景

**PE Static Sentinel**（PE静态安全分析器）是一款面向 Windows PE 文件的安全分析工具。我们的目标是打造一个**模块化、可扩展、专业级**的 PE 文件静态分析平台，帮助安全研究人员和开发人员快速识别 PE 文件中的潜在安全风险。

## 功能全景图

本项目规划了五大核心功能模块，采用**分阶段迭代开发**策略逐步实现：

### 模块一：PE 结构解析引擎 ✅ (当前阶段)
- DOS 头解析与验证
- NT 头解析（PE32/PE32+）
- 节表解析
- 导入/导出表解析
- 资源表解析
- 重定位表解析

### 模块二：静态安全分析引擎 🔜 (未来阶段)
- TLS 回调检测
- 熵值计算与分析
- 危险 API 检测
- 数字签名检查
- 异常行为模式识别

### 模块三：报告生成系统 🔜 (未来阶段)
- JSON 格式导出
- Markdown 报告
- HTML 可视化报告
- 风险等级评估

### 模块四：插件化扩展框架 🔜 (未来阶段)
- 自定义解析器插件
- 自定义分析器插件
- 插件热加载
- 插件市场（社区贡献）

### 模块五：交互式分析工具 🔜 (未来阶段)
- 十六进制查看器
- PE 结构树形浏览器
- 交互式命令行界面
- 批量文件分析

## 技术选型理由

| 技术 | 选择理由 |
|------|----------|
| **C++17** | 性能优先，直接操作内存，零成本抽象 |
| **Windows 原生 API** | 直接使用 `CreateFileMapping`/`MapViewOfFile` 实现高效文件访问 |
| **插件化架构** | 基于接口编程，每个解析器/分析器都是独立插件 |
| **RAII 资源管理** | 智能指针管理所有资源，杜绝内存泄漏 |
| **MSVC + GCC 双编译** | VS2022 用于最终发布，GCC 用于日常快速验证 |
