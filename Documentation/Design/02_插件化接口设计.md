# PE Static Sentinel - 插件化接口设计

## 概述

本项目的核心特色是**插件化架构**。所有功能模块（解析器、分析器）都通过标准接口与核心框架交互，开发者可以轻松添加新的功能而无需修改核心代码。

## IParser 接口设计

### 接口定义

```cpp
class IParser
{
public:
    virtual ~IParser() = default;

    // 初始化解析器 (传入映射后的文件基址和文件大小)
    virtual bool Initialize(const uint8_t* pFileData, size_t fileSize) = 0;

    // 执行解析
    virtual bool Parse() = 0;

    // 获取解析结果 (JSON字符串)
    virtual std::string GetResult() const = 0;

    // 获取错误码
    virtual EErrorCode GetLastError() const = 0;

    // 获取错误描述
    virtual std::string GetErrorDescription() const = 0;
};
```

### 设计说明

1. **两阶段初始化**: `Initialize()` 和 `Parse()` 分离，允许在初始化后设置额外参数再解析
2. **JSON 结果**: `GetResult()` 返回 JSON 字符串，便于序列化和导出
3. **完整错误信息**: 同时提供错误码和人类可读的错误描述

### 实现示例 - 添加新解析器

```cpp
// Include/Parsers/SectionParser.h
class CSectionParser : public IParser
{
public:
    bool Initialize(const uint8_t* pFileData, size_t fileSize) override;
    bool Parse() override;
    std::string GetResult() const override;
    EErrorCode GetLastError() const override;
    std::string GetErrorDescription() const override;

    // 解析器特有的接口
    const SectionInfo& GetSectionInfo() const;
    void SetNumberOfSections(Word numberOfSections);
    void SetOptionalHeaderOffset(size_t offset);

private:
    // ... 成员变量
};
```

## IAnalyzer 接口设计

### 接口定义

```cpp
class IAnalyzer
{
public:
    virtual ~IAnalyzer() = default;

    // 分析器名称
    virtual std::string GetName() const = 0;

    // 执行分析 (传入已解析的PE数据)
    virtual bool Analyze(const PEInfo& peInfo) = 0;

    // 获取分析结果
    virtual std::vector<AnalysisResult> GetResults() const = 0;

    // 是否需要特定解析器支持
    virtual std::vector<std::string> GetRequiredParsers() const = 0;
};
```

### 设计说明

1. **名称标识**: 每个分析器有唯一名称，用于注册和依赖管理
2. **依赖声明**: `GetRequiredParsers()` 返回依赖的解析器名称列表
3. **多结果支持**: 一个分析器可以返回多个分析结果

### 实现示例 - 添加新分析器

```cpp
// Include/Analyzers/EntropyAnalyzer.h
class CEntropyAnalyzer : public IAnalyzer
{
public:
    std::string GetName() const override { return "EntropyAnalyzer"; }

    bool Analyze(const PEInfo& peInfo) override
    {
        // 计算各节的熵值
        // 检测高熵节区（可能加密或加壳）
        return true;
    }

    std::vector<AnalysisResult> GetResults() const override
    {
        return m_results;
    }

    std::vector<std::string> GetRequiredParsers() const override
    {
        return {"SectionParser"}; // 需要节表解析器
    }

private:
    std::vector<AnalysisResult> m_results;
};
```

## 如何添加新解析器

### 步骤

1. **创建头文件**: 在 `Include/Parsers/` 下创建新的解析器头文件
2. **继承 IParser**: 实现 IParser 接口的所有纯虚函数
3. **添加特有接口**: 添加解析器特有的公共接口（如 `GetXxxInfo()`）
4. **创建实现文件**: 在 `Source/Parsers/` 下创建对应的 .cpp 文件
5. **注册解析器**: 在 `PE_Scanner.cpp` 的 `wmain` 中注册

### 注册示例

```cpp
// 在 wmain 中注册
analyzer.RegisterParser(std::make_unique<PE::CSectionParser>());
```

## 如何添加新分析器

### 步骤

1. **创建头文件**: 在 `Include/Analyzers/` 下创建新的分析器头文件
2. **继承 IAnalyzer**: 实现 IAnalyzer 接口的所有纯虚函数
3. **声明依赖**: 在 `GetRequiredParsers()` 中返回依赖的解析器名称
4. **创建实现文件**: 在 `Source/Analyzers/` 下创建对应的 .cpp 文件
5. **注册分析器**: 在 `PE_Scanner.cpp` 的 `wmain` 中注册

### 注册示例

```cpp
// 在 wmain 中注册
analyzer.RegisterAnalyzer(std::make_unique<PE::CEntropyAnalyzer>());
```

## 插件生命周期

```
注册 → 初始化 → 执行 → 获取结果 → 清理
 │        │       │        │        │
 └────────┴───────┴────────┴────────┘
        可重复使用（重新初始化）
```

## 最佳实践

1. **单一职责**: 每个解析器/分析器只做一件事
2. **完整验证**: 对所有输入参数进行验证
3. **详细日志**: 使用 LOG_* 宏记录关键步骤
4. **错误处理**: 所有失败路径必须设置错误码
5. **性能考虑**: 避免在解析器中做过多计算
