## 插件化设计说明

### 设计理念

本项目的核心设计理念是**面向接口编程**。所有解析器和分析器都通过纯虚接口与核心框架交互，实现真正的"插件化"架构。

### 解析器插件 (IParser)

每个解析器负责解析 PE 文件的一个特定部分：

1. **初始化阶段**: 接收文件数据指针和文件大小
2. **解析阶段**: 执行实际的解析逻辑
3. **结果获取**: 以 JSON 字符串形式返回解析结果
4. **错误处理**: 提供错误码和错误描述

### 分析器插件 (IAnalyzer)

每个分析器基于已解析的 PE 信息执行安全分析：

1. **依赖声明**: 声明需要哪些解析器的支持
2. **分析执行**: 基于 PEInfo 执行分析逻辑
3. **结果返回**: 返回多个 AnalysisResult 结构
